# Unity Asset Store publishing

Unity Asset Store profile and package artwork rules that are easy to mix up.

- When William asks for a Unity publish profile banner, he means the Asset Store publisher profile promo image, not promo art for whichever Unity project is open.
- Publisher profile promo media uses a static image at exactly 1200 x 800. Do not confuse it with package key images: cover 1950 x 1300, card 420 x 280, icon 160 x 160, social 1200 x 630.
- Unity says not to use the Unity logo in the publisher profile picture. Treat Unity logo use in other Asset Store imagery as a rejection risk unless Unity explicitly allows it.
