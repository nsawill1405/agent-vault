# William North

William is a solo developer who builds tools for game developers and for himself.
GitHub: [nsawill1405](https://github.com/nsawill1405). Site: [nsawill.co.uk](https://nsawill.co.uk).

Read this note first. This folder overrides everything else in the vault.
Items marked "stated" are rules William gave. Items marked "observed" are defaults read from his repos.

## The short version

- Write simple, longer code that is easy to explain and debug. No clever one-liners (stated).
- No load-bearing hacks. Nothing should work only because of a fragile trick, a magic value, or an accident of ordering (stated).
- Add a linter when a repo lacks one (stated).
- Split work across parallel subagents with different roles to get code written quickly. See [[Parallel Agents]] (stated).
- Always give William a plan before starting work, and keep a task list that you show him when planning and reporting progress (stated).
- Write a new skill when a procedure is worth repeating. See [[Writing Skills]] (stated).
- This vault is the single knowledge base for agents. Record lessons here or in the repo's `AGENTS.md`, not in an agent's private memory (stated).
- Never add Devin or any AI agent as a co-author, and never mention Devin, agents, session links or badges in commits, PRs, comments or docs (stated).
- Merge and release only when William asks (observed).
- Be direct. Short messages, no filler, no marketing tone (observed).
