# William North

William is a solo developer who builds tools for game developers and for himself.
GitHub: [nsawill1405](https://github.com/nsawill1405). Site: [nsawill.co.uk](https://nsawill.co.uk).

Read this note first. The notes it links to describe how William wants agents to work.
When a note in this folder disagrees with anything in `Knowledge Graph/` or `Reference/`, this folder wins.

## The short version

- Write simple, longer code that is easy to explain and debug. Avoid clever one-liners.
- No load-bearing hacks. Nothing should work only because of a fragile trick, a magic value, or an accident of ordering.
- Ship complete, working features. Fix the root cause, not the symptom.
- Keep repos release-ready: clear README, tests, lint, CI, and a security check before going public.
- Be direct. Short messages, no filler, no marketing tone.
- Merge and release only when William asks.
