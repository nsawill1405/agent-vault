# Projects and Interests

Part of [[William North]]. Taste in features and games is in [[Product and Game Design Taste]].

## What William builds (observed)

Tools that remove friction from game development, debugging, and playtesting.
Most are local-first and work inside the editor the developer already uses.

| Project | What it is |
| --- | --- |
| RoVault | Version control for whole Roblox games: instance-level JSON sync to GitHub, with PR and terrain support |
| Fragua | Roblox Studio plugin for custom instance types, enums, and behaviors |
| SignalX | Memory-safe event library for Roblox with priorities, middleware, scoped cleanup, replay, and debugging |
| Hitbox-Plus | Spatial query hitboxes for Roblox with lag compensation hooks and Studio debug visualization |
| Pathfinding-Plus | Crowd-aware Roblox pathfinding with replanning and shared agent coordination |
| Roblox Playtest Logger | Screenshots, pins, console snapshots, and notes during Roblox playtests |
| Unity Playtest Logger | The same idea for Unity |
| Unity Debug Watch | Live debug values for the selected object in play mode, without Debug.Log spam |
| Whirl | Open source whiteboard for flowcharts, mind maps, and sticky notes, with live collaboration |
| recall | Local-first memory for Python apps and AI agents, stored in one SQLite file |
| dustpan | Keeps the macOS Downloads folder tidy with user rules and full undo |
| Shelf | Native macOS utility between the clipboard and the filesystem |
| clipdesk | macOS clipping and multi-platform publisher |
| CRU Studio | Mac-first game studio built with Tauri and Rust/wgpu |
| Orion | Subscription AI tool that helps developers build Roblox games |

## Recurring themes

- Inspecting live values tied to objects, with history and graphs.
- Capturing context during playtests so bugs can be reproduced later.
- Bringing normal software practice (git, types, lint) to Roblox.
- AI tools aimed at game developers.
- Native apps that fix one personal annoyance well.

## Languages

Luau, C#, TypeScript, Python, Go, Swift, and Rust. Luau and C# are the most common for game work.
