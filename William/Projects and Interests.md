# Projects and Interests

Part of [[William North]].

His public projects are listed on his GitHub profile README. Keep it in step with this list through [[Profile README]].

## What William builds (observed)

Tools that remove friction from game development, debugging and playtesting. Most are local-first and work inside the editor the developer already uses.

| Project | What it is |
| --- | --- |
| RoVault | Version control for whole Roblox games: instance-level JSON sync to GitHub. Always call it RoVault, never StudioGit (stated). |
| Fragua | Roblox Studio plugin for custom instance types, enums and behaviors |
| SignalX | Event library for Roblox with priorities, middleware, scoped cleanup and replay |
| Hitbox-Plus | Spatial query hitboxes for Roblox with lag compensation hooks |
| Pathfinding-Plus | Crowd-aware Roblox pathfinding with replanning |
| Roblox Playtest Logger | Screenshots, pins, console snapshots and notes during Roblox playtests |
| Unity Playtest Logger | The same idea for Unity |
| Unity Debug Watch | Live debug values for the selected object in play mode |
| Whirl | Open source whiteboard for flowcharts, mind maps and sticky notes |
| recall | Local-first memory for Python apps and AI agents in one SQLite file |
| dustpan | Keeps the macOS Downloads folder tidy with rules and undo |
| clipdesk | macOS clipping and multi-platform publisher |
| Orion | Subscription AI tool that helps developers build Roblox games |

Do not list CRU Studio or Shelf on his profile README (stated).

## Tool taste (observed)

- One clear job per tool, explained in a short pitch.
- Clean, readable UI. Interactive where it helps, like live graphs.
- Zero cost when unused. Debug tooling must not ship in builds.
- Local-first. No account or server for core features.

## Game ideas (stated)

- Simple core loop that is fun within a minute, with a clear unique selling point.
- Practical to build solo or as a small team.
- No puzzle games when brainstorming Roblox ideas.

## Languages

Luau, C#, TypeScript, Python, Go, Swift and Rust. Luau and C# are the most common for game work.
