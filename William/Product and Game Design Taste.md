# Product and Game Design Taste

Part of [[William North]].

## Tools (observed)

- One clear job per tool. A short pitch should explain it.
- Polished, readable UI. Clean layout, consistent spacing, no clutter.
- Interactive where it helps understanding, like live graphs.
- Zero cost when unused. Debug tooling must not ship in builds.
- Local-first. Do not require an account or a server for core features.

## Game ideas (stated)

- Simple core loop that is fun within a minute.
- A clear unique selling point.
- Practical to build as a small team or solo.
- No puzzle games when brainstorming Roblox ideas.
